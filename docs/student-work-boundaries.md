# Student Work Boundaries

Each learner must own:

- one substantial component or vertical feature;
- one explicit integration boundary;
- normal and failure-path pytest evidence;
- meaningful shared integration or review participation.

A cosmetic UI change, documentation-only task, test-only task, or small utility function is not sufficient by itself.

Use a fake or stub when another dependency is incomplete. Record the real boundary and show how the substitute allowed independent progress.
