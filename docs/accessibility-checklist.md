# Tkinter Accessibility Baseline

- [ ] Essential controls are reachable using Tab and Shift+Tab.
- [ ] Controls activate using Enter or Space where appropriate.
- [ ] Keyboard focus is visible.
- [ ] Controls and status areas use meaningful text labels.
- [ ] Essential state is not communicated only through colour.
- [ ] Text is readable at the supported Windows display scaling.
- [ ] Expected errors appear as understandable text.
- [ ] Important domain behaviour can be tested without visual automation.
